## 📱 Responsive Design

Responsiveness was an important part of the project.

The website adapts its layout based on the user's screen size.

### 💻 Desktop

On larger screens:

* Full navigation is displayed.
* Hero content has larger typography.
* About section uses a two-column layout.
* Skills are displayed in three columns.
* Projects are displayed in three columns.
* Contact information and contact form appear side-by-side.
* Images and content make use of the available screen width.

### 📱 Tablet

On tablet-sized screens:

* Navigation spacing is adjusted.
* Hero typography is resized.
* About section becomes more compact.
* Skills change from three columns to two columns.
* Projects change from three columns to two columns.
* Content receives additional horizontal padding.
* Layouts are adjusted to prevent overcrowding.

### 📱 Mobile

On smaller screens:

* Desktop navigation links are hidden.
* A hamburger menu icon is displayed.
* Hero typography is reduced.
* Contact information becomes more compact.
* About section changes to a single-column layout.
* Skills are displayed in one column.
* Projects are displayed in one column.
* Contact information and the form stack vertically.
* Contact form inputs become vertically arranged.
* Images scale according to the available screen width.

## 🧠 Key Concepts Practiced

This project provided practical experience with several important frontend concepts.

### 1. CSS Flexbox

Flexbox was used to control the layout of:

* Navigation
* Hero content
* Contact information
* About section
* Buttons
* Form elements
* Footer content

---

### 2. CSS Grid

CSS Grid was used for structured card layouts, particularly:

* Skills
* Projects

The number of columns changes depending on the viewport width.

---

### 3. Responsive Design

Media queries were used to create different layouts for:

* Desktop
* Tablet
* Mobile

This helped ensure that the website remains usable across different devices.

---

### 4. CSS Pseudo-elements

Pseudo-elements such as `::after` were used to create visual effects without requiring additional HTML elements.

For example, navigation links use a pseudo-element to create their animated underline.

---

### 5. CSS Transitions

Transitions were used to create smooth visual changes when users interact with:

* Buttons
* Cards
* Images
* Links
* Social media icons

---

### 6. CSS Keyframes

The `@keyframes` rule was used to create the continuous animation of the back-to-top button.

---

### 7. Anchor Navigation

The website uses section IDs and anchor links to allow users to navigate between different parts of the single-page website.

For example:

```html
<a href="#projects">Project</a>
```

connects the navigation link to:

```html
<section id="projects">
```
