# Allen Smith — Personal Portfolio Website

A responsive single-page portfolio website built with HTML and CSS.

This project was created as part of my internship journey with Syntecxhub. The goal was to build a clean, responsive and interactive portfolio that showcases my skills, projects and contact information.

## 🚀 Features

- Responsive design for desktop, tablet and mobile
- Smooth scrolling navigation
- Animated hover effects
- CSS transitions and animations
- Animated back-to-top button
- About section
- Skills section
- Featured projects section
- Contact form
- Social media links
- Mobile navigation layout
- Consistent dark and green colour scheme

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Media Queries
- CSS Animations
- CSS Transitions
- Font Awesome
